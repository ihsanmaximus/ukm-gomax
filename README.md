# MAXIMUS Lab — Website UMKM

## Struktur proyek
- `index.html` — halaman utama.
- `assets/css/` — stylesheet global, modul, dan penyesuaian halaman.
- `assets/js/main.js` — interaksi navigasi mobile.
- `assets/images/` — gambar dikelompokkan berdasarkan section.

## Gambar yang perlu disiapkan
Simpan gambar dengan nama dan lokasi berikut:
- `assets/images/hero/maximus-hero-owner.png`
- `assets/images/intro/maximus-intro-laptop.jpg`
- `assets/images/about/maximus-about-founder.png`
- `assets/images/portfolio/maximus-portfolio-kuliner-01.jpg`
- `assets/images/portfolio/maximus-portfolio-fashion-01.jpg`
- `assets/images/portfolio/maximus-portfolio-produk-01.jpg`

Gunakan penamaan standar: `[project]-[section]-[description]-[number].[extension]`.

## Sebelum dipublikasikan
1. Ganti nomor `628xxxxxxxxxx` dengan nomor WhatsApp tujuan.
2. Ganti tautan sosial media placeholder.
3. Pastikan seluruh gambar di atas sudah tersedia.
4. Uji tampilan di lebar 360, 390, 768, 1024, dan 1440 px.
5. Pastikan link navigasi, CTA, dan FAQ berfungsi.

## Menjalankan lokal
Buka folder proyek di VS Code lalu jalankan dengan local server.
